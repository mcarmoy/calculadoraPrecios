Módulo calculadora
******************

Calculadora de precios.

Módulo que permite calcular un precio con IVA, aplicar un descuento y
obtener el precio final aplicando descuento e IVA.

calculadora.IVA_GENERAL = 21.0

   Porcentaje de IVA general que se aplica por defecto.

calculadora.aplicar_descuento(precio, descuento)

   Aplica un porcentaje de descuento a un precio.

   Parámetros:
      * **precio** (*float*) -- Precio original. Debe ser mayor o
        igual que 0.

      * **descuento** (*float*) -- Porcentaje de descuento, entre 0 y
        100.

   Devuelve:
      Precio con el descuento aplicado, redondeado a dos decimales.

   Tipo del valor devuelto:
      float

   Muestra:
      **ValueError** -- Si el precio es negativo o el descuento no
      está entre 0 y 100.

calculadora.calcular_con_iva(precio, iva=21.0)

   Calcula el precio con IVA incluido.

   Parámetros:
      * **precio** (*float*) -- Precio base sin IVA. Debe ser mayor o
        igual que 0.

      * **iva** (*float*) -- Porcentaje de IVA a aplicar (por defecto
        21).

   Devuelve:
      Precio con IVA, redondeado a dos decimales.

   Tipo del valor devuelto:
      float

   Muestra:
      **ValueError** -- Si el precio o el IVA son negativos.

calculadora.calcular_precio_final(precio, descuento, iva=21.0)

   Calcula el precio final aplicando primero el descuento y después el
   IVA.

   Parámetros:
      * **precio** (*float*) -- Precio base sin IVA.

      * **descuento** (*float*) -- Porcentaje de descuento, entre 0 y
        100.

      * **iva** (*float*) -- Porcentaje de IVA a aplicar (por defecto
        21).

   Devuelve:
      Precio final con descuento e IVA, redondeado a dos decimales.

   Tipo del valor devuelto:
      float

   Muestra:
      **ValueError** -- Si algún valor no es válido.

calculadora.main()

   Pide un precio y un descuento y muestra los tres cálculos.
